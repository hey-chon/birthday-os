BIRTHDAY OS — for bebii

Upload all six website files in this folder together to Netlify.
Keep index.html at the top level. No build command is needed.
For local testing, serve this folder with any static web server; JavaScript modules require HTTP rather than opening index.html directly.

Type guide to see the commands.
pkg install birthday-os: detailed 16-package simulated installation, then Birthday OS ASCII.
pkg install ascii.art: installs the uploaded portrait and unlocks ascii help, ascii list, and ascii 1.
pkg update: simulated repository refresh.
Ctrl+C cancels a package operation. Reboot resets the simulated installation state.

This is a fictional terminal. No real packages, downloads, device access, or system commands are used.
Birthday: October 17, 2026 (Asia/Manila).
Main birthday website: https://birthday-website.netlify.app (planned destination; availability not verified).

The birthday launcher is unavailable until birthday-os finishes installation. Cancelling installation or rebooting leaves it locked. Installing ascii.art does not unlock it.
